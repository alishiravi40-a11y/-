## E18 — مکان چک (قاعده‌های استخراج‌شده)
هلو مکان چک را صریح نگه نمی‌دارد و آن را از وضعیت (`Check_Event.State`) و حساب‌های تعریف‌شده بانک و صندوق می‌سازد:

| وضعیت هلو | رویداد جدید | از ← به |
|---|---|---|
| D | received | حساب شخص پرداخت‌کننده ← حساب چک صندوق (`Cash.Sarfasl_Code2`) |
| J | deposited_for_collection | مکان فعلی ← حساب وصولی بانک (`ACOUND_N.Dar_*`) |
| V (در وصول) | collected | حساب وصولی ← حساب بانک |
| V + شخص | endorsed_to_party | مکان فعلی ← حساب شخص (در «۰۰۰۰۰» از ردیف‌های سند، W-32) |
| R | returned_from_bank | حساب وصولی ← صندوقی که چک آخرین بار در آن بود |
| M | moved_between_cashboxes | صندوق ← صندوق |
| B | returned_to_payer | مکان فعلی ← حساب پرداخت‌کننده |
| S | returned_by_endorsee | گیرنده خرج ← صندوق |
| P (پرداختی) | issued | اسناد پرداختنی بانک (`ACOUND_N.Par_*`) ← حساب گیرنده |
| V (پرداختی) | paid_by_bank | حساب بانک ← اسناد پرداختنی |
| O (پرداختی) | settled_otherwise | طرف از سند ← اسناد پرداختنی |

سند هر رویداد = **بدهکار «به»، بستانکار «از»** به مبلغ چک.

| نتیجه | مقدار |
|---|---|
| چک منتقل‌شده | ۱۲,۵۱۵ |
| رویداد منتقل‌شده | ۳۵,۶۱۴ (received ۱۲,۲۲۵ · deposited ۱۰,۰۲۵ · collected ۹,۱۰۶ · moved ۱,۱۱۵ · endorsed ۹۵۳ · returned_from_bank ۷۵۵ · returned_to_payer ۷۱۹ · returned_by_endorsee ۴۷۹ · paid_by_bank ۸۵ · issued ۸۰ · settled_otherwise ۷۲) |
| برابری سند با هلو | **۶,۲۲۹ از ۶,۲۳۰ سند**: نوع ۰ ۳,۸۸۴/۳,۸۸۴، نوع ۴ ۴۵/۴۵، نوع ۵ ۱۶/۱۶، نوع ۷ ۳۳/۳۳، نوع ۸ ۲,۲۵۱/۲,۲۵۲ |
| تنها استثنا | ۱ سند، ۲ چک: خرج پیش از تاریخ دریافت (W-34، همان مورد E08). زنجیره مکان مدل جدید آن را رد می‌کند |
| اجرای دوباره | بی‌اثر |

## E19 — اسناد خزانه بدون چک و اسناد انتظامی
هر سند هلو به **سندهای نوع‌دار مدل جدید، یکی برای هر رویداد واقعی** تفکیک می‌شود، با قاعده `core.treasury_posting_lines` (یا `core.guarantee_event_lines`) دوباره ساخته می‌شود و با هلو مقایسه می‌شود.

| نوع سند هلو ← سند جدید | تعداد | نتیجه |
|---|---|---|
| انتقال بانکی ← transfer | ۴,۷۲۹ | برابر |
| انتقال بانکی ← transfer + bank_fee (کارمزد در همان سند) | ۵ | برابر |
| دریافت ← receipt | ۲,۲۵۰ | برابر |
| دریافت ← receipt + transfer (سند مرکب) | ۱ | برابر |
| دریافت ← transfer (نوع نادرست) | ۳ | برابر |
| پرداخت ← payment (از جمله ۱ پرداخت با تخفیف نقدی خرید) | ۲۷۲ | برابر |
| پرداخت ← receipt (نوع نادرست) | ۱ | برابر |
| کارمزد بانکی ← bank_fee | ۲۱۰ | برابر |
| کارمزد بانکی ← transfer به تنخواه / payment هزینه / receipt (نوع نادرست) | ۱۱ / ۶ / ۱ | برابر |
| واریز نقد ← transfer | ۱ | برابر |
| دریافت (نوع ۴) ← گرفتن ضمانت | ۱۳۸ | برابر در سطح حساب |
| خودکار (نوع ۰) ← آزادسازی ضمانت | ۱۳۴ | برابر در سطح حساب |
| **جمع** | **۷,۷۶۲** | **۷,۷۶۲ برابر؛ هیچ سند طبقه‌بندی‌نشده** |

- کارمزد: ۳۰۲ مورد و **همه** روی حساب کارمزد تعریف‌شده همان بانک (`ACOUND_N.Wage_*`) ثبت شده‌اند.
- ۷۶ کارمزد انتقال در یک ردیف بستانکار ادغام‌شده با مبلغ انتقال ثبت شده‌اند (بدون ردیف جدا) و از خالص سند بازشناسی می‌شوند.
- اسناد نوع ۷ «کارمزد بانکی» علاوه بر ۱۸ سند غیرکارمزد بالا، در ۳۳ سند برای ۱,۰۱۶ رویداد چک (خرج چک به پیش‌پرداخت) هم استفاده شده‌اند (W-33).
- رویدادهای چک با طرف «۰۰۰۰۰» (هیچ‌کس): ۴۷۷ خرج، ۱۲۰ صدور، ۷ دریافت (W-32).
- حساب‌های انتظامی ضمانت در هلو **بدون شخص** ثبت می‌شوند و ضامن فقط در شرح متنی است (W-35).
